Section 1The page

The page title is Search, Filter & Investigate Individual RFIs. The question on the header is which RFIs require review, follow-up, or document action. The first three pages count the project, the document changes, and the parties. This page is the row behind each count.

Filters sit on the left: an RFI number search, a party list, status, discipline, and document impact. Four cards sit across the top. The register table fills the rest of the page. It is sorted by RFI number. Question Summary is the start of fact_rfi.question, shortened so the row stays one line. The full question and the response stay in the fact table.

Section 2Live report

The published report is rif_vis. The bar under the frame switches pages: executive, Drawing & Specification Change Analysis, COORDINATION & RESPONSIBILITY, and RFI Register.

This chapter is dashboard 4. Use the arrows beside 4 of 4 to open the RFI Register. Page 1 is the executive dashboard. Page 2 is Drawing & Specification Change Analysis. Page 3 is COORDINATION & RESPONSIBILITY.

Section 7How to read it

Use the earlier pages to see the pattern, then use this page to find the row. Status Open is the eight-RFI backlog, all with CT. Document impact Both is the 16 RFIs that change a drawing and a specification. An RFI number in the search box opens that one record, with its submitter, its tasked party, and the start of the question.

The party list looks like every organisation on the project. It filters the submitter. A tasked party such as AE or CT has to be read from the Responsible Party column, or from the coordination page.
