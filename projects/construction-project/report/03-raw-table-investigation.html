Section 1Raw table

02_load_rfi_excel.py wrote data/processed/raw_rfi.csv. The original workbook was left unchanged. Cell values were copied as stored, including Excel date serials. Each row also records the source file and the time the table was loaded.

03_raw_rfi_investigation.py then checked that table. It did not clean or transform the rows. The saved checks are in data/processed/profiling/.
