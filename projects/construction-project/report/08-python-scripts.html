Section 2Local pipeline

Scripts 01 through 19 have been run. The workbook stays in data/raw/rfi_log.xlsx. Raw dates stay as Excel serials. The clean table holds RFI-001 through RFI-107. The DuckDB file holds fact_rfi and the four dimensions. Unity Catalog holds digital_engineering.ml.rfi_discipline_classifier version 1 and digital_engineering.ml.rfi_issue_type_classifier version 1. Both aliases are champion. Each model expects a GTE embedding vector. The document-impact runs are logged in rfi_document_impact. The GTE classifier is the one to keep: Yes recall 0.68 with 5 false Yes calls.

08_preview_rfi_tables.py opens rfi.duckdb read-only and prints every table. Question, response, and notes are shortened in that printout.

Section 3Next script

20_register_document_impact_model.py registers the GTE document-impact classifier as digital_engineering.ml.rfi_document_impact_classifier and sets the alias champion. That model scored accuracy 0.84 and Yes recall 0.68 on 70 RFIs. Its input is the embedding vector from databricks-gte-large-en, built from the question. It does not take raw text, and it does not change the RFI tables.
