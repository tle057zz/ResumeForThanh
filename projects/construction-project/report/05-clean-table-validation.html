Section 3What each check covers

The column check requires those nine fields, in that order. The identifier check requires the rows to stay in order from RFI-001 to RFI-107, with no gaps and no duplicates.

Every kept row must have a question, a submitting party, a tasked party, and a real calendar date. Answered is allowed only when a response is present and response_available is Yes. Open is allowed only when the response is blank and response_available is No.

The last check reads the five excluded identifiers — the section label and numbers 108 through 111 — and confirms none of them appear in the clean table.
