Section 1Feature run

06_build_rfi_features.py read data/processed/rfi_clean.csv and wrote data/processed/rfi_features.csv. The clean table was not changed. All 107 identifiers remain RFI-001 through RFI-107.

The new fields are derived. Where a question already names a discipline, that label is kept. Otherwise the opening of the question is matched to keywords. Drawing and specification flags come from the notes. A later model can replace these rules.

FieldHow it is set
disciplineStated discipline in the question, otherwise keyword rules
issue_typeKeyword rules on the question
drawing_update_requiredYes, No, or Unknown from the notes
spec_update_requiredYes, No, or Unknown from the notes
document_update_requiredYes when either update flag is Yes; No when both are No; otherwise Unknown
question_word_countWords in the question
response_word_countWords in the response

Section 4Document updates

51 notes say no specification or drawing update is required. Those rows are No on all three flags. A note that a specification or drawing was updated is Yes. A blank note, or a note that only says an attachment was sent, stays Unknown.

FlagYesNoUnknown
Drawing update required185138

Document update is Yes for 19 RFIs: 16 notes update both the specification and the drawing, two update a drawing only, and one updates a specification only.

Section 5Word counts

Questions run from 9 to 335 words, with a median of 69. Responses run from 0 to 109 words, with a median of 16. Eight responses have no words, the same eight open RFIs.
