Section 1Files to load

09_export_powerbi.py reads data/processed/rfi.duckdb and does not change it. It writes data/processed/powerbi/rfi_star_schema.xlsx, with one sheet per table, and one CSV beside that workbook. A later run replaces those files.

Every chart is a count, a filter, or a text lookup of these 107 RFIs. fact_rfi is one row per RFI, RFI-001 through RFI-107. No fact key is missing from a dimension, and every dimension row is used at least once.

TableRowsWhat a visual shows
dim_date9Received date

dim_party is one list. from_party_key and tasked_party_key are two relationships to that list. In this extract the roles do not share a name.

Discipline, issue type, status, and the document flags come from 06_build_rfi_features.py. They are the labels to draw. The workbook Status column is blank on every source row.

Section 5Status, length, and documents

Status is Answered when the response has text, and Open when it is blank. response_available repeats that split as the text values true and false. The eight open IDs are RFI-086, RFI-092, RFI-093, RFI-095, RFI-096, RFI-100, RFI-106, and RFI-107.

StatusRFIsresponse_availableResponse text
Answered99truePresent
Open8falseBlank, word count 0

Every question has text. Question length runs from 9 to 335 words, with a median of 69. Response length runs from 0 to 109 words, with a median of 16. The eight zeros are the open RFIs. Use the word-count columns for a length visual. Question and response text belong in a table or a tooltip.

The document flags are Yes, No, or Unknown, read from notes. Unknown means the note is blank or only says an attachment was sent. Document update is Yes when either drawing or spec is Yes. Those 19 Yes rows are 16 that update both, 2 that update a drawing only, and 1 that updates a specification only. The 51 No rows say no specification or drawing update is required.

FlagYesNoUnknown

notes has seven distinct phrases, so it is a label for a chart, not a long narrative. Fifty-one notes say no update is required, 35 are blank, and 15 say an updated specification or drawing was included. The other four notes record an attachment, a drawing update tied to RFI-47, a redundant update with RFI-08, or a specification-only update.
